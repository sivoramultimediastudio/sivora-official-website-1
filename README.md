# SIVORA brand website

Static responsive website with three official brand logos.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` inside this directory.

## Deploy on Render through GitHub
1. Create a GitHub repository and upload the contents of this directory (including `assets`).
2. In Render choose **New → Static Site**, connect GitHub and select your repository.
3. Use build command `echo "Static website ready"` and publish directory `.` (root).
4. Deploy and verify the public `onrender.com` URL. You may alternatively use Render Blueprint with `render.yaml`.
5. Add a custom domain and DNS records using Render's current dashboard instructions if desired.

## Before public launch
Replace placeholder contact section with confirmed business emails, addresses, WhatsApp and social links. Review business claims, legal/privacy policy, and confirm the final wording. This is an informational website; online payments, catalog inventory, and customer forms require additional implementation.
